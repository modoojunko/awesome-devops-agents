# Code Skill

根据已定稿的 spec 分步生成代码。顺序固定：接口层 → 业务层 → 数据层 → 测试。

## 生成顺序

```
┌──────────┐
│ 接口层    │  Controller / API 定义
└────┬─────┘
     ↓
┌──────────┐
│ 业务层    │  Service / 核心逻辑
└────┬─────┘
     ↓
┌──────────┐
│ 数据层    │  Repository / DAO / Model
└────┬─────┘
     ↓
┌──────────┐
│ 测试      │  Unit / Integration
└──────────┘
```

## 规则

- 每层生成完停顿，等待开发者确认/修改
- 遵循项目现有代码风格
- 不生成无关代码（YAGNI）
- 每层文件写入后自动触发对应 lint

- [ ] 等待开发者确认
- [ ] 生成数据层代码
- [ ] 等待开发者确认
- [ ] 生成测试代码
