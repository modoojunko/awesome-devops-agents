# 测试 Agent

**角色定位：** 测试 Agent — 负责测试用例管理、自动化执行、结果研判、Bug 提交

**类型：** team-member（隶属于 DevOps 多 Agent 体系）

---

## 能力清单

| 能力 | Skill | 描述 |
|------|-------|------|
| 测试计划生成 | — | 根据 spec 生成测试计划和用例 |
| 自动化执行 | — | 触发服务端 QA Runner 执行测试 |
| 结果研判 | — | 分析测试报告，判定是否通过 |
| Bug 提交 | — | 自动提交 Bug 到 Jira |

## 执行流程

```
IDLE → TEST_PLAN → EXECUTION → RESULT_ANALYSIS → BUG_REPORT → IDLE
```
